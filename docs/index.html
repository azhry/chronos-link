# ADR-0014: Asynchronous Task Offloading

## Status Accepted

## Context As the monolith grows, the synchronous processing of image uploads is causing timeout errors (HTTP 504) in the edge gateway. We need a way to process these tasks out-of-band while maintaining a responsive UI.

## Decision We will implement a **Producer-Consumer pattern** using **Redis Streams** and a dedicated worker pool in Go.

## Consequences // Positive - P99 latency reduced by 85% for upload endpoints. - Decoupled scaling of workers from web pods.

// Negative - Adds Redis as a critical infrastructure dependency. - Requires complex error-handling for failed task retries.

## Metadata Provider: anthropic/claude-3-5-sonnet Signal: git-diff --staged (internal/worker/*)

Deployment & Installation

Deploy the reasoning engine to your local environment in seconds using uv.

# 1. Clone the core engine
git clone https://github.com/azhry/chronos-link
cd chronos-link

# 2. Install dependencies via uv
uv pip install .

# 3. Configure credentials
cp .env.example .env
// Edit .env with your LLM keys

# 4. Execute Probe & Synthesis
uv run chronos-link --workspace /path/to/your/project
